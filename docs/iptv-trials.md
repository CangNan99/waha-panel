# IPTV 自动试用

在“自动回复设置 → IPTV 自动试用”保存供应商密钥、频道范围和每日上限，确认供应商后台 Demo 已设为 12 小时，再为当前 WhatsApp 会话启用。供应商密钥、时长确认和每日额度共享；会话开关及频道范围独立。

本集成固定使用 Activation Panel 官方文档的 HTTPS API 地址，创建 M3U 试用时发送 `sub=99`。默认 `pack=all`，每日全局最多自动开通20个，可调整为1–1000。12小时为供应商后台设置，软件不会通过本地计时修改或延长供应商账号。显示的预计到期时间以本地成功申请时刻加12小时计算；供应商接口当前仅返回到期日期。

客户明确要求测试 IPTV 时，AI 发出结构化申请，后台再次检查客户意图、会话连接、自动回复时段、人工接管、当前配置和额度后开通。询价、介绍和播放故障不会直接开通。每位客户永久只有一次试用机会，不按天、月份或账号有效期重置。有效期间重复请求只能取回原账号，过期后拒绝再次开通。领取记录保留在共享数据库中，跨会话、服务重启、删除会话、关闭再启用功能或更换供应商密钥都不会恢复资格；界面没有重置资格或再次赠送试用的入口。

手机号格式的 c.us 与 s.whatsapp.net 身份按相同客户永久去重。WhatsApp只提供无法确认手机号的LID时，系统转人工核对，不自动创建账号，以免同一客户通过不同身份格式重复领取。核验之前不能把未知LID视为一位新客户。更换手机号码后的同一自然人，仍需要人工识别；系统无法仅凭两个不同号码判断是否同一个人。

API 密钥和试用登录信息使用现有面板数据密钥加密。管理员读取配置只能看到“已配置”状态；开通记录不返回账号或密码。自动发送凭据仍会出现在对应客户的 WhatsApp 对话中，但面板归档的 AI 上下文及动态记忆输入会隐藏本次试用凭据。总结、建议回复、优化翻译、自动跟进、单条 AI 翻译和阿里云机器翻译也在最终请求边界统一过滤已知试用凭据。

创建请求超时、连接异常、无效返回或进程中断后的未决记录不会自动再次创建。请在供应商面板人工核对。发送失败保留已创建的账号，客户之后再次申请时可复用。关闭自动开通、人工接管或连接周期变化会取消未发送的旧结果；已创建账号仍保存。若在供应商调用前取消而没有实际开通，客户下一条新的申请可重新预留资格。供应商已经创建的账号不能通过本地回滚撤销。

“检查供应商接口”只读取已保存账号状态和套餐列表，不创建账号。不自定义套餐时，供应商可能返回 `Empty custom bouquet`，不影响使用 `all`。

本次手机端修复让聊天详情继承外层工作区剩余高度，并在支持的浏览器中跟随可视视口变化。浏览器自动化已覆盖手机宽度、横屏、缩小视口、多行输入和夜间主题；真实手机软键盘及安全区仍需在实际设备上验证。
