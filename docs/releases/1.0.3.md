# waha-panel 1.0.3

发布日期：2026-09-19（Asia/Shanghai）

## 本次更新

- 支持一次性跟进延迟：24 小时、3 天、7 天、15 天，均从任务创建时间起算。
- 跟进内容可由 AI 基于最近 20 条消息生成，也可使用固定文案翻译模式。
- 任务创建后收到新的入站消息，或进入人工接管状态时，自动跟进会跳过。
- 发送结果进入终态后不再自动重试不确定结果。
- 手工标签与 AI 标签分离；摘要成功生成后，AI 标签会整体替换为最新结果。
- 当前会话摘要会覆盖上一份报告，不保留历史版本。
- 人工接管后 5 小时恢复 AI：从最近一次确认的人工发送或接管点击时间计时；若没有人工消息，则以接管点击时间为准。
- QR 码占位图采用磨砂且不可扫描的样式；仅在图片响应成功后替换为真实图片。
- 新增数据库迁移 `007_chat_engagement.sql`。

## 明确不变

- WAHA API 不变。
- WAHA 消息与会话结构不变。
- Docker Compose 网络配置不变。
- Nginx 配置不变。
- 现有 `1.0.2` 回滚镜像与标签保留不变。
