# waha-panel 1.0.18

发布日期：2026-10-23（Asia/Shanghai）。

## 全局翻译

- 默认使用阿里云机器翻译专业版 Translate 接口。
- 聊天设置支持在阿里云专业版和 AI 模型翻译之间手动切换。
- 切换引擎会取消旧请求并按当前引擎重新翻译，缓存按引擎隔离，不自动回退。
- AI 模型翻译使用销售辅助 AI 的 OpenAI 兼容服务配置。

## IPTV 自动试用

- 试用资格改为按“WhatsApp 技术会话 + 当前聊天身份”限制，每个聊天窗口只生成一次。
- @c.us、@s.whatsapp.net 和 @lid 均可直接申请，不再要求先确认手机号。
- 同一窗口重复申请复用原账号；不同聊天窗口分别计算资格。
- 供应商创建或复用成功、消息发送成功并完成状态记录后，才添加只读系统标签“IPTV测试过”。
- 发送失败、结果未知或发送前取消不会添加标签；标签写入失败不会回滚已发送消息。
- 旧数据库的 IPTV 全局唯一约束会迁移为聊天窗口级约束，保留已有记录。

## 自动回复延迟

- 设置页新增 0–120 的按会话延迟强度滑杆，默认 100。
- 100 保持热对话 1–5 秒、冷对话 20–100 秒、输入模拟 6–15 秒。
- 其他值按比例缩放，0 适合测试；设置只影响标准 AI 自动回复。

- Python 全量回归 269 项通过，前端 Node 测试 22 项通过。
- 升级会保留 SQLite、WhatsApp 会话、媒体和系统标签数据。
- 面板镜像：docker.io/cangnan88/waha-panel:1.0.18。

升级前请备份数据库、.env、secrets/ 和当前镜像；回滚时只切换面板镜像，不要用旧数据库覆盖升级后新增记录。
