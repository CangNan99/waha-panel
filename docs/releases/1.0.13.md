# waha-panel 1.0.13

## 更新内容

- 修复全局翻译开关的会话行为：重新打开窗口后开关默认保持关闭，不保存上次的开关状态。
- 重新打开窗口时只恢复服务端缓存中已经完成的 `READY` 译文；缓存未命中时不会自动调用阿里云，用户手动开启翻译后才继续处理缺失消息。
- 为机器翻译缓存增加稳定的消息身份，并通过迁移 009 兼容旧版加密消息引用，避免服务重启或安全引用轮换后已完成译文丢失或重复翻译。

## 兼容性与数据

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.13`
- WAHA 镜像继续使用 `devlikeapro/waha:latest-2026.9.1`，不修改 WAHA 服务行为。
- 迁移 009 只为机器翻译缓存增加消息身份字段和索引，不删除聊天、会话、媒体、SQLite 数据或已有译文。
- 升级前应备份 `.env`、面板 SQLite、WAHA 会话和媒体卷，并同时保存面板数据加密密钥。

## 发布与回滚

- 发布前验证镜像拉取、数据库迁移、聊天页面、缓存恢复和面板健康响应。
- 若验证失败，将 `PANEL_IMAGE`/`PANEL_VERSION` 回滚到 `1.0.12`；恢复时保留持久化卷，并确认面板数据加密密钥与数据库匹配。
