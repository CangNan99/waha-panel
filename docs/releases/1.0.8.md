# waha-panel 1.0.8

## 更新内容

- 修复 WAHA 返回 WhatsApp CDN 头像地址时，管理面板因媒体地址校验而无法加载头像的问题。
- 头像代理仅允许面板自身的 WAHA 地址，以及 HTTPS 的 `pps.whatsapp.net` 和 `mmg.whatsapp.net`，不会把 WAHA API Key 转发给 WhatsApp CDN。
- 将二维码未刷新状态的占位层改为磨砂玻璃纹理，增加 SVG 噪声层、高光和渐变，保留平滑显示二维码的过渡效果。
- 将默认 WAHA 镜像更新为 `devlikeapro/waha:latest-2026.9.1`。

## 兼容性与数据

- 保留 1.0.7 的面板容器内存限制、Argon2 并发控制、聊天管理和自动回复设置。
- WAHA 会话、媒体卷、面板 SQLite 卷和内部网络配置保持不变。
- 本版本未改变 WAHA API 行为；更新仅切换到指定的 WAHA 镜像标签并修复管理面板头像代理。

## 发布与回滚

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.8`
- WAHA 镜像：`devlikeapro/waha:latest-2026.9.1`
- 更新前应备份 `.env`、面板 SQLite 数据、WAHA 会话和媒体卷。
- 若验证失败，可将面板回滚到 `1.0.7`，将 WAHA 回滚到 `latest-2026.8.2`；回滚不删除持久化卷。
