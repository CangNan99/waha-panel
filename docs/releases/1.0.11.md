# waha-panel 1.0.11

## 更新内容

- 过滤没有正文、说明或媒体内容的 WhatsApp 空消息记录，避免聊天界面出现空白气泡；正常文字、说明和纯媒体消息继续显示。
- 打开或切换聊天时定位到最新一条消息；处于底部附近时自动跟随新消息，查看历史消息时保留当前位置，并提供“有新消息 · 回到最新”操作。
- 管理员登录成功后在同一浏览器配置文件中保持固定 7 天；支持退出登录，并在修改密码或停用管理员时撤销已有会话。
- 保留 Basic Auth 兼容入口、CSRF 校验、SQLite 数据卷和现有 WAHA 会话及媒体卷。

## 兼容性与数据

- 面板容器继续使用 512 MiB 内存限制和现有 Argon2 并发控制。
- WAHA 镜像继续使用 `devlikeapro/waha:latest-2026.9.1`，不修改 WAHA 服务行为。
- 新增 `admin_sessions` SQLite 表，只保存哈希后的会话令牌、管理员身份、创建时间、过期时间和撤销信息。
- 不删除 WAHA 原始消息，不改变现有 SQLite、WAHA 会话、媒体卷和内部网络。

## 发布与回滚

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.11`
- 更新前备份 `.env`、面板 SQLite、WAHA 会话和媒体卷。
- 若验证失败，将 `PANEL_IMAGE`/`PANEL_VERSION` 回滚到 `1.0.10`，WAHA 保持 `latest-2026.9.1`；回滚不删除持久化卷。
