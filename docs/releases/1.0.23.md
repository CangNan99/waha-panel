# waha-panel 1.0.23

发布日期：2026-11-06（Asia/Shanghai）。

## IPTV 自动开卡并发保护

- 保留 1.0.22 对 IPTV 上下文短消息（例如“测试”“试用”“test”）的受控触发，以及旧版 `unknown` 记录的单记录恢复重试。
- 对仍处于 `creating` 的自动开卡记录继续返回待处理状态，不创建重试任务，避免供应商调用尚未返回时重复申请账号。
- 新增回归测试覆盖无重试任务的进行中记录，确认不会产生第二次供应商请求。

## 配置、数据和回滚

- 本版本只调整面板 IPTV 状态机和发布元数据，不删除或覆盖历史客户消息、卡密或供应商配置。
- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.23`，平台 `linux/amd64`。
- WAHA 服务继续使用现有版本并独立管理；升级只替换面板容器，保留持久化卷。
- 升级前备份 `.env`、Compose 覆盖配置、面板数据和构建源目录。验证失败时把 `PANEL_IMAGE`/`PANEL_VERSION` 恢复为 `1.0.22` 并只重建面板服务，不删除持久化卷。

## 验证

- IPTV 服务、集成和路由聚焦测试、Python 全量回归、前端语法检查、`py_compile` 和 `git diff --check` 均需通过后再发布。
- 生产发布后核对面板和 WAHA 容器状态、面板启动日志、认证边界、SQLite 重试状态和实际运行代码；不输出供应商密钥、账号、密码或客户标识。
