# waha-panel 1.0.25

发布日期：2026-11-06（Asia/Shanghai）。

## 产品图片库与 AI 直接发图

- 新增管理员“产品图片”页面，可以上传 JPG、PNG、WebP，维护标题、说明模板、产品标签、优先级、主图和启用状态。
- AI 新增 `send_product_image` 单工具调用。只有客户当前消息明确包含对应标签时才允许发送；标签无匹配、图片停用或同一优先级存在多个主图时回退普通文字。
- 每条客户消息最多发送一张图片。图片发送由产品图片请求账本和通用自动发送账本共同防重，重复 webhook、刷新或重复工具调用不会重复发送。
- WAHA 返回未知状态会保存为 `UNKNOWN`，不会自动重试；管理员可以在日志和图片库状态中继续核对。
- 全局自动发送开关默认开启，每日上限默认 20 张。关闭开关会阻止所有聊天自动发图，不影响人工发送。

## 安全和数据

- 上传、预览和发送都会重新校验图片真实格式、MIME、扩展名、大小、像素和 SHA256；文件名不接受路径分隔符，图片文件使用原子替换写入。
- 图片管理接口和私有预览需要管理员身份及 CSRF；响应不会返回绝对路径、SHA256 路径或公开图片 URL。
- SQLite 新增产品图片设置、资产、标签和发送账本表。`panel_data` 卷同时保存 `panel.sqlite3` 和 `product-images/`，备份和恢复必须成对处理。

## 升级、验证和回滚

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.25`，保持 WAHA 服务版本和容器不变，只替换面板容器。
- 升级前备份 `.env`、Compose 覆盖配置、面板 SQLite、`panel_data` 卷、`product-images/`、WAHA 会话和媒体卷；备份目录生成 `panel_data-manifest.txt`，核对 SQLite 与图片目录状态。
- 迁移只新增产品图片表，不删除历史数据。升级失败时把 `PANEL_IMAGE` 和 `PANEL_VERSION` 恢复为 `docker.io/cangnan88/waha-panel:1.0.24`，只重建面板服务；不要删除持久化卷。
- 若要恢复某个时间点，必须同时恢复 SQLite 和 `product-images/`，否则会出现孤立元数据或孤立文件。

## 验证

- Python 产品图片、管理路由、AI 集成、聊天发送、IPTV 和聊天升级回归测试通过。
- 前端 JavaScript 语法、迁移幂等、`py_compile`、`git diff --check` 和 Docker 构建检查在发布前执行。
