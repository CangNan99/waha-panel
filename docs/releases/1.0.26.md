# waha-panel 1.0.26

## GLM 多模态模型

- 新增按会话配置的语言模型、视觉理解模型、视觉推理模型和图像生成模型。
- 客户发送图片时，面板可以下载、校验并交给 GLM 视觉模型识别，再沿用现有上下文和业务规则自动回复。
- 同时配置视觉理解和视觉推理时，自动回复优先使用视觉推理模型。
- 新增聊天页面的图片理解、图片推理、图像生成预览和确认发送操作。
- GLM API Key 使用 `PANEL_DATA_ENCRYPTION_KEY` 加密保存，旧的语言模型配置继续兼容。

## 可靠性与安全

- 生成图片引用增加并发锁、短时缓存、过期清理和发送幂等状态机。
- 生成图片下载禁止自动跟随重定向，不向图片 CDN 转发 GLM API Key。
- GLM 请求并发限制为两项，并在日志中保留实际会话技术名。
