# waha-panel 1.0.26

## GLM 多模态模型

- 新增按会话配置的语言模型、视觉理解模型、视觉推理模型和图像生成模型。
- 客户发送图片时，面板可以下载、校验并交给 GLM 视觉模型识别，再沿用现有上下文和业务规则自动回复。
- 同时配置视觉理解和视觉推理时，自动回复优先使用视觉推理模型。
- 新增聊天页面的图片理解、图片推理、图像生成预览和确认发送操作。
- GLM API Key 使用 `PANEL_DATA_ENCRYPTION_KEY` 加密保存，旧的语言模型配置继续兼容。

## 可靠性与安全

- 生成图片引用增加并发锁、短时缓存、过期清理和发送幂等状态机。
- 生成图片下载禁止自动跟随重定向，不向图片 CDN 转发 GLM API Key。
- GLM 请求并发限制为两项，并在日志中保留实际会话技术名。

## 客户统计与产品图片

- 状态概览按账号显示今日新客户数和总客户数，统计按 Asia/Shanghai 当天边界计算并隔离账号。
- 产品图片资产支持产品名称、SKU 和别名的规范化精确匹配，按来源优先级和标签优先级选择唯一启用主图；管理页增加匹配字段和图片图标。
- 客户消息中的图片继续通过受保护媒体接口加载，点击后可在预览窗口中放大、缩小、复位、拖动和关闭。
- GLM 服务地址同时兼容根地址和已填写完整接口路径，避免重复拼接 `/chat/completions` 或 `/images/generations`。
- 修复旧版跟进任务使用稳定非 UUID 请求号时触发 `INVALID_REQUEST_ID` 的问题，自动发送账本继续保持幂等。
- 兼容 AI 通道遇到 DNS、连接或超时时会自动重试一次；认证错误不重试，并继续使用脱敏错误码记录。
- AI 回复成功后，根据客户当前消息中的明确购买或高意向表达，自动写入持久化系统标签 `购买意向` 或 `高意向`；标签写入失败不会阻断回复。
- 新增按账号配置的 AI 主动营销：默认暂停，可设置客户空闲天数、扫描周期、每日上限、同一客户冷却天数和营销目标提示词；后台只处理私聊空闲客户，并自动跳过群聊、人工接管、近期入站、退订客户和生成失败场景。
- 主动营销使用独立发送账本、Asia/Shanghai 日上限和按月批次键；发送结果不确定时不会计入上限，也不会重复发送。
