# waha-panel 1.0.5

## 修复内容

- 面板容器默认内存上限从 `256m` 提高到 `512m`，为 SQLite、Python 运行时和并发请求预留更稳定的余量。
- 管理员 Argon2id 认证使用 `32 MiB / 2 次迭代 / 2 lanes`，并通过全局并发闸门将同时进行的 Argon2 派生限制为 2 个，避免多对话页面并发认证造成瞬时内存峰值。
- 已有的高成本 Argon2id 密码哈希在成功登录后渐进式重哈希到新参数；不会记录或输出明文密码。
- Argon2 内存分配失败会返回可识别的 `ADMIN_AUTH_UNAVAILABLE` 服务不可用错误，不再伪装为泛化的面板处理失败。

## 安全说明

本版本以降低瞬时内存压力和提高并发稳定性为目标，Argon2id 参数低于 1.0.4。面板仍要求管理员密码，且成功登录会按新参数更新哈希；请确保面板继续使用 HTTPS、强密码和访问控制。

## 升级与回滚

升级只重建 `waha-panel` 服务，保留 `panel_data`、WAHA 会话和媒体卷。若需回滚，将 `PANEL_IMAGE`/`PANEL_VERSION` 改回 `1.0.4` 并将 `mem_limit` 改回 `256m`，然后只重建面板服务；旧哈希仍可验证。
