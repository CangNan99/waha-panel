# waha-panel 1.0.22

发布日期：2026-11-06（Asia/Shanghai）。

## IPTV 测试触发和旧记录恢复

- 客户在已有 IPTV 对话上下文中只发送“测试、试用、体验、test、trial、teste”等短消息时，也会进入受控的自动测试卡密流程。
- 普通聊天中的短词、询价、播放故障、否定和取消表达继续被拦截，不会因为单独出现“测试”而开卡。
- 对旧版本遗留的 `unknown` 自动开卡记录，如果数据库中没有重试任务，客户再次明确请求时会补建同一条记录的创建重试，不新增第二条自动资格记录；仍在上游开通中的 `creating` 记录会保持待处理，避免并发重复申请。
- 已存在的重试任务继续保持单记录单飞；供应商成功后只发送该记录对应的账号，手动卡密记录和人工发送路径保持独立。

## 配置、数据和回滚

- 本版本只使用现有 IPTV 表和重试表，不删除或覆盖历史客户消息、卡密或供应商配置。
- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.22`，平台 `linux/amd64`。
- WAHA 服务继续独立管理；升级只替换面板容器，保留 `waha-release_panel_data`、`waha-release_sessions` 和 `waha-release_media`。
- 升级前备份 `.env`、Compose 覆盖配置和面板数据。验证失败时把 `PANEL_IMAGE`/`PANEL_VERSION` 恢复为 `1.0.21` 并只重建面板服务，不删除持久化卷。

## 验证

- IPTV 服务、集成和路由聚焦测试通过后，再运行 Python 全量回归、前端语法检查、`py_compile` 和 `git diff --check`。
- 生产发布后核对面板和 WAHA 容器状态、面板启动日志、健康接口、SQLite 重试状态和实际访问结果；不输出供应商密钥、账号、密码或客户标识。
