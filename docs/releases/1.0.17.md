# waha-panel 1.0.17

发布日期：2026-10-19（Asia/Shanghai）。

## IPTV 自动试用

- 客户明确要求测试 IPTV 后，AI可通过受控工具申请M3U试用账号，供应商参数为`sub=99`，默认`pack=all`。
- 每位客户永久只有一次试用机会。同一手机号跨会话去重，有效期内重复申请仅取回原账号；过期后不再开通，日期、重启、会话变化和密钥更新不会恢复资格。
- 无法核验客户手机号的WhatsApp身份别名转人工处理，避免重复领取。供应商调用前取消且未实际创建的请求不消耗资格。
- 供应商创建结果不确定时停止重试；发送失败保留原账号。创建和发送前重新检查连接、自动回复时段、人工接管和配置状态。
- 供应商密钥与试用凭据加密保存。设置页提供会话开关、密钥状态、只读供应商检查、每日限额和脱敏记录，默认全局每天最多20个。
- 12小时时长需要在供应商后台将Demo设为12小时，并在设置页确认。软件不延长供应商账号；本地到期时间为预计值。

## 凭据保护

- 面板归档、自动回复、动态记忆、摘要、建议、跟进、优化翻译和第三方翻译请求统一过滤已知IPTV凭据。
- 密钥和账号不会从管理员配置读接口或试用记录接口返回。客户收到的试用消息保留实际登录信息。

## 手机聊天输入框

- 修复聊天区高度叠加外层导航后，底部输入框和发送按钮被裁切的问题。
- 聊天区继承剩余高度，并跟随可视视口变化，适配键盘缩短区域、横屏、多行输入和夜间模式。

## 验证与升级

- Python完整回归242项、前端22项；IPTV服务和集成33项，包含长期资格、并发、跨会话、未知结果、取消和凭据过滤。
- 手机浏览器覆盖多种尺寸、缩短可视视口、多行和夜间。实体手机软键盘仍需在实际设备上确认。
- 升级新增3张IPTV表，保留现有数据与会话；从已试部署版本升级时不会重新创建或清空记录。
- 面板镜像为`docker.io/cangnan88/waha-panel:1.0.17`。WAHA继续独立管理，本次不要求升级消息服务。
- 升级前备份数据库、配置、凭据和原镜像；回退只切换面板镜像并保留当前业务数据，不用旧数据库覆盖升级后新增记录。
