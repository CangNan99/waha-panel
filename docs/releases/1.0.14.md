# waha-panel 1.0.14

## 更新内容

- 按 Bento Grid 视觉规范重构多会话状态页、自动回复设置页和聊天管理页的布局、颜色、字体层级、间距、卡片和响应式规则。
- 主题选择器只保留白天（`daylight`）与夜间（`night`）；未知旧值安全回退到白天。
- 保留现有自动回复、AI、知识库、客户记忆、翻译、人工接管、二维码、手机号配对、管理员和消息收发功能。
- 增加视觉主题约束测试，并修正与当前 DOM 表达一致的历史测试断言。

## 兼容性与数据

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.14`
- WAHA 镜像继续使用 `devlikeapro/waha:latest-2026.9.1`，不修改 WAHA 服务行为。
- 本版本不引入数据库迁移，不删除或重建 SQLite、WhatsApp 会话或媒体数据卷。
- 主题存储仍使用 `waha-panel-theme`，未知值会回退为 `daylight`。

## 发布与回滚

- 发布前验证前端内联脚本、Python 模板编译、三页 HTML 生成、容器启动和面板 HTTP 响应。
- 宝塔更新只替换 `waha-panel` 容器，保留 `waha-release_panel_data`、`waha-release_sessions` 和 `waha-release_media`。
- 若验证失败，将 `PANEL_IMAGE`/`PANEL_VERSION` 回滚到 `1.0.13`，重新创建面板容器；恢复时保留持久化卷，并确认面板数据加密密钥与数据库匹配。
