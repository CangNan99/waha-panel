# waha-panel 1.0.19

发布日期：2026-10-24（Asia/Shanghai）。

## IPTV 播放地址修复

- 修复供应商明确返回成功、已经创建 Demo，但播放链接缺少域名时被记为结果未知的问题。
- 自动回复设置新增共享的“播放服务器地址”。填写公开 HTTP(S) 服务器地址，可带端口；留空关闭地址补全。
- 仅补全缺域名的 `/get.php` 链接，并要求唯一且完整的账号密码。完整供应商链接保持原样，其他异常继续拒绝。
- 加强地址校验，拒绝内网、本机、无效端口、带登录信息的服务器地址，以及数字形式的 IPv4 本机地址别名。
- 每个聊天窗口仅领取一次；发送成功并保存发送状态后添加“IPTV测试过”系统标签。历史待核对记录需要人工匹配，系统不会自动重新开通。

## 配置和升级

- 升级后在“自动回复 → IPTV 自动试用”按供应商提供的地址填写播放服务器。默认留空，不会自动猜测播放域名。
- API Key、已创建账号及原领取记录继续保留。播放服务器设置在会话之间共享。
- 播放服务器配置只用于补全地址；频道列表、账号实际到期时间和实际播放情况需要以供应商及播放器结果为准。
- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.19`，平台 `linux/amd64`。
- WAHA 继续独立管理，面板升级只替换面板容器。

## 验证

- 回归覆盖缺域名成功响应、完整地址保留、异常凭据和地址拒绝、共享配置、加密保存、重复领取保护及发送后的标签顺序。
- 发布前执行 Python 全量回归、前端语法和行为检查，并核对镜像与发布提交。

升级前请备份数据库、`.env`、`secrets/` 和当前镜像。回滚时切换到原面板镜像，保留当前持久化数据库，避免覆盖升级后的新增记录。
