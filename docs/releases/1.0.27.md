# waha-panel 1.0.27

## 发布内容

- 保留 1.0.26 已发布的 GLM 多模态、按账号客户统计、产品图片精确匹配、产品图片图标、客户图片预览缩放、跟进恢复和购买/高意向标签能力。
- 新增按账号周期扫描的 AI 主动营销，默认暂停，可设置客户空闲天数、扫描周期、每日上限、同一客户冷却天数和营销目标提示词。
- 主动营销自动跳过群聊、人工接管、近期入站、退订客户、生成失败和发送结果不确定的场景，并使用 Asia/Shanghai 日上限和幂等发送账本。
- 本版本只更新管理面板镜像，不更新 WAHA 镜像、WhatsApp 会话卷、媒体卷或面板数据卷。

## GitHub / 宝塔更新口令

在已部署宝塔服务器执行：

```bash
cd /root/waha-panel/
```

确认 `.env` 中的面板镜像为：

```dotenv
PANEL_IMAGE=docker.io/cangnan88/waha-panel:1.0.27
PANEL_VERSION=1.0.27
```

然后只更新面板容器：

```bash
docker compose pull waha-panel
docker compose up -d --no-deps --force-recreate waha-panel
```

更新后检查：

```bash
docker compose ps
docker compose logs --tail=100 waha-panel
```

## 回滚

回滚时将 `PANEL_IMAGE` 恢复为升级前保存的镜像标签，保留当前 SQLite 和 Docker 持久化卷；不要用旧数据库覆盖升级后产生的新记录。发布前应保存 `.env`、`secrets/`、Compose 配置、面板 SQLite 和产品图片目录。
