# waha-panel 1.0.6

## 修复内容

- 保留 1.0.5 的 `512m` 面板内存上限、Argon2id `32 MiB / 2 次迭代 / 2 lanes` 和最多 2 个并发派生。
- 将 Argon2id 密码验证移出 SQLite `BEGIN IMMEDIATE` 写事务，避免多对话页面并发认证造成 `database is locked`。
- 相同凭据的并发认证请求合并为一次密码验证，并使用有上限、有过期时间的进程内摘要缓存；数据库中的账号状态和密码哈希仍在写入前重新确认。
- 处理密码重哈希与并发密码更新的竞态，避免合法请求被误记为失败登录。

## 发布与回滚

- Docker 镜像：`docker.io/cangnan88/waha-panel:1.0.6`
- 仅重建 `waha-panel` 服务，保留现有 `panel_data`、WAHA 会话和媒体卷。
- 可回滚到 `1.0.5`；若回滚到 `1.0.4`，需同时恢复其 `256m` Compose 限制。1.0.5 的 Argon2 参数已低于 1.0.4，旧哈希仍可验证。
