# waha-panel 1.0.9

## 更新内容

- 修复管理员账号集合接口的路由解包错误，管理员新增账号恢复正常。
- 增加当前 WhatsApp 账号头像的面板代理、图片校验、成功/失败缓存和默认回退头像。
- 手机端进入聊天详情时隐藏全局顶部栏，同时保留最近聊天列表布局。
- 复用聊天头像节点，减少备注、标签和状态刷新造成的头像闪烁。
- 翻译请求按客服/客户角色分开缓存，并在结果卡片中显示消息来源和对应表达目的。

## 兼容性与数据

- 保留 1.0.8 的 512 MiB 面板内存限制、Argon2 并发控制、二维码磨砂动效和聊天管理设置。
- WAHA 镜像继续使用 `devlikeapro/waha:latest-2026.9.1`，不修改 WAHA 服务行为。
- 不改变现有 SQLite、WAHA 会话、媒体卷、面板数据卷和内部网络。

## 发布与回滚

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.9`
- 更新前备份 `.env`、面板 SQLite、WAHA 会话和媒体卷。
- 若验证失败，将面板镜像回滚到 `1.0.8`，WAHA 保持 `latest-2026.9.1`；回滚不删除持久化卷。
