# waha-panel 1.0.24

发布日期：2026-11-06（Asia/Shanghai）。

## 全局翻译总开关

- 翻译开关改为所有聊天共用的单一总开关，开启后每个聊天窗口都按当前引擎处理已加载的非中文消息，关闭后所有聊天停止新翻译。
- 开关状态持久化到面板 SQLite，刷新页面、切换聊天和重新登录后保持一致。
- 继续保留已完成的译文缓存展示；关闭总开关后不会继续发起新的翻译请求。
- 翻译引擎选择和凭据仍保持原有独立配置，不会影响销售辅助 AI 或自动回复模型。

## 数据迁移、配置和回滚

- 新增全局翻译设置的 `enabled` 字段，旧数据库自动迁移，默认值为关闭；不会删除聊天、消息、译文缓存或翻译凭据。
- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.24`，平台 `linux/amd64`。
- WAHA 服务继续使用现有版本并独立管理；升级只替换面板容器，保留持久化卷。
- 升级前备份 `.env`、Compose 覆盖配置、面板数据和构建源目录。验证失败时把 `PANEL_IMAGE`/`PANEL_VERSION` 恢复为 `1.0.23` 并只重建面板服务，不删除持久化卷。

## 验证

- 翻译服务、迁移、路由和聊天页面契约测试、Python 全量回归、前端语法检查、`py_compile` 和 `git diff --check` 均需通过后再发布。
- 生产发布后核对面板和 WAHA 容器状态、启动日志、认证边界、全局开关字段和实际运行代码；不输出翻译凭据或客户数据。
