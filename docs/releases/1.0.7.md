# waha-panel 1.0.7

## 更新内容

- 客户备注优先显示在聊天身份位置；未填写备注时继续显示手机号。
- 聊天列表与会话头部展示最多四个标签，手动标签优先，并保持紧凑布局。
- 修复客户头像读取与头像代理缓存，减少头像显示异常。
- 优化手机端聊天管理排版，使 AI 接管和人工回复操作在窄屏上保持可见。
- 自动回复上下文改为双向读取：上下文滑块范围为 5–50，默认每侧 5 条消息；客户侧和面板发出的消息都会纳入上下文。
- 增加图片、视频、音频和文件等媒体消息的自动回复开关，默认仅处理私聊文字消息。
- 扫码连接增加磨砂占位、平滑二维码揭示、过期请求保护和手机号配对等待状态。
- 管理面板品牌统一为 `WhatsAPP AI管理面板`。

## 资源与兼容性

- 保留 1.0.6 的面板容器 `512m` 内存上限、Argon2id 参数和并发派生控制。
- WAHA 镜像、WAHA 会话、媒体卷、面板 SQLite 卷和内部网络配置不变。
- 本版本仅更新管理面板，不修改 WAHA 服务行为或 WAHA 镜像版本。

## 发布与回滚

- Docker 镜像：`docker.io/cangnan88/waha-panel:1.0.7`
- 更新时只重建 `waha-panel` 服务，保留现有 `panel_data`、WAHA 会话和媒体卷。
- 若健康检查或页面验证失败，可将面板镜像回滚到 `1.0.6`；回滚不会删除或重建持久化卷。
