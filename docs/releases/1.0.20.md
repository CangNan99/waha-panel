# waha-panel 1.0.20

发布日期：2026-10-29（Asia/Shanghai）。

## IPTV 测试卡密和聊天分页

- 支持中文、英语、葡萄牙语、西班牙语、法语、阿拉伯语、土耳其语、德语、俄语、意大利语，以及日语、韩语、荷兰语、越南语和印尼语的常见 IPTV 测试请求表达。
- AI 未返回受控 IPTV 工具调用时，后端按明确意图规则兜底；只有系统自动发送的 IPTV 邀请才允许用“是/好的/请发”等短答确认，手动卡密不会触发自动试用。
- 自动创建、供应商未知结果、供应商拒绝和发送失败进入持久化重试队列；重试使用指数退避、单记录单飞，创建成功后发送失败只重发已有账号。
- 增加手动“生成并发送”入口，可选测试、1个月、3个月、6个月和12个月。手动卡密不受自动测试领取历史限制；手动创建失败不自动重建，已创建账号的发送失败只重发原账号。
- 手动请求编号按供应商、会话和客户聊天窗口隔离，避免跨客户重放请求编号复用旧卡密。
- 聊天列表加载更多后，实时刷新和轮询保留已加载窗口；超过单次接口上限时分段重取，不再缩回100条以内。

## 配置、数据和回滚

- 新增 `iptv_manual_cards`、`iptv_trial_retries` 和手动请求作用域索引迁移；升级只新增表/索引，不覆盖既有 SQLite 数据。
- API Key、账号、密码和播放地址继续加密保存，不返回到普通日志、浏览器响应或 AI 上下文。
- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.20`，平台 `linux/amd64`。
- WAHA 服务继续独立管理；本版本只替换面板容器，保留 `waha-release_panel_data`、`waha-release_sessions` 和 `waha-release_media`。
- 升级前备份数据库、`.env`、`secrets/`、生效 Compose/override 和当前面板镜像。失败时只切换回原面板镜像并保留业务卷，避免用旧数据库覆盖升级期间新增记录。
