# waha-panel 1.0.15

## 更新内容

- 二维码卡片自适应正方形图像与四周留白，修复窄屏及内容网格缩放时的底部裁切；已连接会话继续阻止新登录码请求。
- 五个主菜单共用常驻导航，无整页刷新地切换工作台、聊天管理、自动回复、状态概览和系统日志；支持深链接、浏览器前进后退、草稿隔离和未保存设置提示。
- 状态概览展示受管理会话连接状态、服务检查、自动回复配置、人工接管、跟进任务和近期异常；失败的统计显示暂不可用，刷新失败保留旧数据并标记过期。
- 系统日志支持会话、时间、级别、事件和关键词筛选，稳定游标翻页、详情复制及可选实时检查；敏感字段在写入、读取和搜索边界脱敏，筛选失败保留上次成功状态。
- 打开、重开和返回聊天时定位最新消息；客户资料与消息并行加载，媒体或译文区域增高时继续跟随；用户主动阅读历史时停止自动跟随，并保留已经加载的旧消息。
- 备注、AI 总结和 AI 标签增加中文约束。备注支持主动转换、候选预览和明确保存；专名、产品型号、必要金额及链接保留，错误生成不会覆盖有效旧资料。
- 白天与夜间聊天分别调色，背景固定于消息视口，不随长对话滚走。
- 修复发送响应跨客户清空草稿/附件，以及备注保存期间覆盖新编辑的问题；登录失效时清理页面和敏感内存，离开页面暂停轮询与事件流。

## 验证

- 本地 190 项 Python 测试、22 项前端测试通过；构建检查覆盖 4 份内联脚本和 7 个模块。
- 浏览器覆盖 25 个页面/尺寸组合、20 次连续切页、500 条消息、延迟媒体、错误恢复、中文边界及跨客户异步操作。
- 截图与浏览器夹具均为合成数据，没有真实客户内容或真实登录二维码。手机键盘和缩放布局通过可用视口模拟，真实设备仍应现场核验。

## 兼容性与数据

- 面板镜像：`docker.io/cangnan88/waha-panel:1.0.15`；WAHA 镜像继续沿用 `devlikeapro/waha:latest-2026.9.1`。
- 本版本没有新增数据库迁移或索引，不批量改写历史非中文资料，不重建 WhatsApp 会话或媒体卷。
- 中文转换候选仍需人工核对姓名、否定关系和金额关联；数字/链接检查不代替语义确认。
- 大规模历史日志的查询耗时应结合实际数据量观察；概览计数仅代表面板已记录和当前可访问的数据。

## 升级与回滚

升级前保存当前镜像、配置和一致数据库备份。仅替换管理面板容器，保留当前业务数据、WAHA 会话与媒体卷。若升级异常，将面板镜像与版本恢复到 `1.0.14` 后仅重建面板；界面回退不自动覆盖业务数据库。

本次按“宝塔部署与验收完成后，再公开 GitHub 与 Docker Hub”的顺序发布；具体发布结果以对应平台的正式版本和镜像摘要为准。
