# waha-panel 1.0.16

## 自动回复只处理当前周期的新消息

- 面板启动、WhatsApp 账号登录或重连、关闭后重新开启自动回复时，为每个会话建立独立的新消息处理起点。
- 使用消息的原始发生时间，历史未读消息、补推消息和历史回填只用于显示、归档及上下文，不因此触发 AI 回复。
- 支持秒和毫秒时间；缺少有效时间、明显未来时间或无法区分的新旧边界会跳过发送。
- 发送前再次检查连接、开关、回复时间段及人工接管状态。重连、重新开启或人工接管后恢复 AI，不会复活旧任务。

## 会话切换

- 修复会话卡片点击事件冒泡到外层后又被切回原账号的问题。
- 头像、名称、状态和箭头均可切换；选中会话与详情、日志、聊天和设置入口保持一致。
- 隔离旧请求，支持快速 A→B→A 取消、页面前进后退和定时刷新。

## AI 没有有效结果时不发送

- 移除“默认固定回复文案”设置及后台固定兜底。
- AI 未配置、超时、报错、返回空或无效结果、未完成或拒绝结果时，跳过发送并记录原因。
- 自动订单工具失败或进入人工处理时，不再自动向客户发送等待文案。独立人工工单流程保留。
- 已保存的旧固定文案不再参与自动回复；历史聊天和业务资料保留。

## 验证

- Python 208 项及前端 22 项回归测试。
- JavaScript 内联脚本和模块语法检查。
- 桌面和手机宽度的会话切换、慢请求、快速切换、返回导航、定时刷新及设置页面验收。
- 隔离镜像测试、运行文件指纹、数据库完整性、配置和 HTTPS 登录保护检查。

功能测试使用合成消息和模拟发送。WAHA 仍作为独立组件管理，本次发布不要求升级消息服务。
